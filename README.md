This project applies Logistic Regression to the Titanic dataset to predict passenger survival based on features such as age, gender, ticket class, fare, and embarkation port. The workflow includes handling missing values (imputing age, fare, and embarkation), encoding categorical variables like sex and embarkation, dropping irrelevant features such as cabin and ticket, and standardizing the dataset for training. After splitting the data into training and testing sets, a Logistic Regression model is trained and evaluated using accuracy, confusion matrix, and classification reports. Additionally, feature importance is analyzed through model coefficients and visualized to understand the influence of different passenger attributes on survival. Finally, predictions are saved into a CSV file for further use or submission, making the project a complete end-to-end example of preprocessing, modeling, evaluation, and result storage.
